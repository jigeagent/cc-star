## 一、hot.md 跨会话续接（核心增量）

### 背景
新会话开始时，Claude 不知道上次做到哪。FTS5 检索是"提问→命中"模式，session_start 时没有注入。

### 方案
新增 `data/hot.md`，作为跨会话的短期工作状态快照。

**格式：**
```markdown
---
updated_at: 2026-06-29T10:00:00Z
project: cc-star
status: 开发完成，准备发版
blocked: 无
summary: Phase 5-7 已完成，v0.7.0 全部就绪
next: 跟踪 consolidation 第一次运行
---

## 当前工作
- cc-star v0.7.0 发版终检通过
- consolidation worker 已修复 load_spacy 循环 bug
- 定时任务已注册 23:00

## 待办
- [ ] 跟踪 consolidation 首次运行结果
```

**生命周期：**
| Hook | 动作 |
|------|------|
| `Stop`（会话结束） | 自动写入/更新 hot.md |
| `SessionStart`（新会话） | 自动读取 hot.md 注入上下文 |
| 过期检测 | >24h 未更新 → 前缀 `(上次会话 24h+ 前)` |
| 手动重置 | 用户可清空 hot.md 内容 |

**配置：**
```yaml
memory:
  hot_enabled: true          # 开关
  hot_max_age_hours: 24      # 过期阈值
  hot_max_tokens: 500        # 注入长度限制
```
